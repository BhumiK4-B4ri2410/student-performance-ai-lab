# Student Performance ML Trainer

A machine learning web application that predicts student performance using uploaded CSV datasets.

## Features
- Upload and preview CSV datasets
- Select input features and target column
- Train Random Forest regression or classification models
- Display model evaluation metrics
- Make predictions using user-entered values
- Automatically handle missing values and categorical data

## Technologies Used
- Python
- FastAPI
- Pandas and NumPy
- Scikit-learn
- HTML, CSS and JavaScript
